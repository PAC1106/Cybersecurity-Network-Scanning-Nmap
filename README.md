# Network Scanning using Nmap

## Project Overview
This project demonstrates network scanning using Nmap to identify live hosts, open ports, and services on a local network.

---

## Objectives
- Discover active devices on the network
- Identify open ports
- Detect running services
- Perform detailed analysis using an aggressive scan

---

## Tools Used
- Nmap
- Zenmap
- Command Prompt

---

## Commands Used
nmap -sn 192.168.1.0/24
nmap -sS 192.168.1.99
nmap -A 192.168.1.99

---

## Key Findings
- Active host detected: 192.168.1.99  
- Open ports: 135, 139, 445, 3306, 1521, 7070  
- Services detected: RPC, NetBIOS, SMB, MySQL, Oracle
